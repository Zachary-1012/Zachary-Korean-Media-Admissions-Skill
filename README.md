# Zachary Korean Media Admissions Skill

A public, interactive Korean-learning site designed around applications to **Seoul National University (SNU)** and **Chung-Ang University (CAU)** in media communication, media marketing, advertising, PR, international communication, and adjacent fields.

## Open the live course

**GitHub Pages:**  
https://zachary-1012.github.io/Zachary-Korean-Media-Admissions-Skill/

## Degree modes

The page can switch between:

- **Undergraduate** — 학부 / 학사과정
- **Master’s** — 석사과정 *(default)*
- **PhD** — 박사과정

Each mode changes the study-plan emphasis rather than reusing the same admissions logic.

## What is included

- 48 lessons across 12 stages
- TOPIK-oriented Korean
- SNU / CAU school and major routes
- media / advertising / marketing / PR vocabulary
- research-method and academic Korean
- master’s and PhD interview practice
- undergraduate application mode
- drama-inspired Shadowing scenes
- 2025/2026 drama contexts
- browser/system Korean TTS
- application planning and mock interview tools

## Audio

The 🔊 buttons use the browser/device’s **system Korean TTS** (`speechSynthesis`, `ko-KR`).

They are **not Korean drama actor recordings** and the repository does not contain Netflix/TVING drama audio.

## Drama copyright boundary

The site uses drama titles and settings as learning context. Longer learning dialogues are original/adapted educational scenes rather than copied full scripts.

## Admissions accuracy

Admissions rules change. Always verify the exact school, degree level, year/semester, and application cycle through official university sources before applying.

This project is an independent learning resource and is **not affiliated with Seoul National University or Chung-Ang University**.
